# Tidy

Личная утилита для Windows.

## Скачать

Откройте [Releases](../../releases/latest) и скачайте `Tidy-vX.Y.Z.zip`.

## Запуск

1. Распакуйте архив в любую папку.
2. Запустите `Tidy/Tidy.exe`. Python и другие программы не нужны.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — у программы нет цифровой подписи:
   нажмите «Подробнее» → «Выполнить в любом случае».

Настройки и журналы программа хранит рядом с собой, в папке `Tidy/data`.

## Если что-то пошло не так

В окне программы нажмите **«Отчёт об ошибке»** — на Рабочем столе появится файл
`Tidy-report-….zip`. Отправьте его автору.
